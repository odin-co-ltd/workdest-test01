이 화면휴대폰 홈 아이콘
  1. 시트는 지우거나 바꾸지 않습니다. 사무실은 지금처럼 PC에서 시트를 씁니다.
  2. 시트 안의 Apps Script에 화면 파일을 추가하고 "웹앱으로 배포"하면 주소가 나옵니다. 작업자 휴대폰 홈 화면에 아이콘으로 올립니다.
  3. 재단·쫄대·엣지는 버튼 한 번으로 완료. 포장(조립은 완성)은 사진을 찍어 저장이 성공해야 완료로 바뀝니다.
  4. 사진은 드라이브 폴더에, "고유ID / 공정 / 사진 링크 / 시각 / 작업자" 한 줄은 시트에 남습니다. 체크 열(재단·쫄대·엣지·포장)에도 TRUE가 기록됩니다.
  5. 작업자 이름은 휴대폰에 한 번 저장해 두고 씁니다. 로그인 없음.
